# Application

This directory contains the Next.js application for the Gamers N Geeks redesign project.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## Development

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## Documentation

Project documentation lives in the repository root under:

```
/docs
```

The application should follow the standards defined in:

- DESIGN_SYSTEM.md
- PROJECT_VISION.md
- ARCHITECTURE.md

## Note

This application is intentionally separated from the repository root to keep client documentation, assets, and source code organized.
