# Navigation Specification

## Purpose

Organize the store's large catalog into understandable, scalable groups.

## Primary Categories

Initial proposed groups:

- Trading Card Games
- Miniatures
- Board Games
- Role-Playing Games
- Paint and Hobby
- Models and Gunpla
- Collectibles
- Events
- TCG Singles

## Desktop

- Horizontal primary navigation
- Mega menus for high-volume categories
- Logical subcategory grouping
- Avoid exposing every Shopify collection at once

## Mobile

- Hamburger-triggered drawer
- Expandable category groups
- Clear back navigation
- Large touch targets
- No bottom navigation during Sprint 1

## External Destinations

TCG Singles may link to the existing TCGPlayer Pro storefront.

External transitions must be clearly labeled when appropriate.

## Accessibility

- Keyboard navigation
- Correct ARIA expanded states
- Logical tab order
- No hover-only functionality

## Acceptance Criteria

- Users can reach major categories within two interactions
- Duplicate Shopify collection handles are not exposed in labels
- Menu remains readable without overwhelming the user
