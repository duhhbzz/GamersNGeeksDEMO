# Header Specification

## Purpose

Provide branding, search, navigation, account access, and cart access.

## Required Elements

- Gamers N Geeks logo
- Primary navigation
- Search
- Account link
- Cart link
- Mobile menu trigger

## Desktop Behavior

- Sticky header
- Logo aligned with navigation
- Full search input remains visible
- Mega-menu support for large category groups

## Mobile Behavior

- Compact logo
- Hamburger menu trigger opens a drawer
- Search accessible without excessive scrolling
- Account and cart remain discoverable
- No bottom navigation during Sprint 1

## Accessibility

- Semantic navigation landmark
- Keyboard-operable menus
- Visible focus states
- Accessible labels for icon-only controls
- Escape key closes open menus

## Acceptance Criteria

- Header remains usable at all supported widths
- No navigation item requires precision clicking
- Desktop search remains visible without opening another interface
- Search and cart are reachable in one interaction
