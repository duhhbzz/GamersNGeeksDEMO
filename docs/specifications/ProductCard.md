# Product Card Specification

## Purpose

Display products consistently across featured sections and collection pages.

## Required Information

- Product image
- Product title
- Price
- Availability
- Product details link

## Optional Information

- Original price
- Sale badge
- New badge
- Category
- Quick-add control
- Wishlist control

## States

- Available
- Low stock
- Sold out
- Sale
- New arrival

## Interaction

- Subtle hover elevation
- Clear focus state
- Image should not shift layout while loading
- Quick add should only appear where technically appropriate
- Wishlist should only appear where technically appropriate

## Accessibility

- Descriptive image alternative text
- Product title available as text
- Sale pricing announced clearly
- Status must not rely only on color

## Acceptance Criteria

- Cards maintain consistent dimensions
- Product names remain readable
- Pricing and availability are immediately visible
