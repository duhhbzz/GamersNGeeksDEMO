# Button Specification

## Variants

### Primary

- Brand-green background
- Dark text
- Used for primary page actions

### Secondary

- Dark surface
- Visible border
- Used for alternative actions

### Ghost

- Transparent background
- Used for low-priority actions

### Destructive

- Error color
- Reserved for destructive operations

## Sizes

- Small
- Medium
- Large

## States

- Default
- Hover
- Focus
- Active
- Disabled
- Loading

## Accessibility

- Visible focus ring
- Minimum practical touch target
- Disabled state communicated semantically
- Loading state retains an accessible label

## Acceptance Criteria

- Buttons are visually consistent
- Text remains readable in every state
- Buttons are distinguishable from ordinary links
