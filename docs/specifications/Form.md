# Form Specification

## Components

- Text input
- Search input
- Text area
- Select
- Checkbox
- Radio group
- Form label
- Help text
- Validation message

## Requirements

- Every field has a visible label
- Required fields are clearly identified
- Validation messages are specific and actionable
- Placeholder text does not replace labels

## States

- Default
- Hover
- Focus
- Filled
- Disabled
- Error
- Success

## Accessibility

- Labels associated with controls
- Errors connected with aria-describedby
- Keyboard accessible
- Sufficient contrast
- Focus order follows visual order

## Acceptance Criteria

- Forms can be completed without a mouse
- Errors explain how to resolve the problem
- Controls remain usable on mobile
