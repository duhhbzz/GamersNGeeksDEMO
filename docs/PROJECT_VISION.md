# 🎲 Gamers N Geeks Modern Redesign

---

# Project Vision

This project is a complete front-end redesign concept for the Gamers N Geeks website.

The goal is to modernize the customer experience while preserving the existing Shopify infrastructure, inventory management, and business workflows.

This is not intended to replace Shopify.

Instead, this project demonstrates how thoughtful UX, modern design, and improved information architecture can transform the online experience without disrupting store operations.

---

# Mission

Build a website that feels like walking into an amazing local game store.

Customers should immediately discover:

- What's happening this week
- What products are available
- Where the store is located
- How to participate in the community
- Why Gamers N Geeks is worth visiting

# User Experience Goals

Within 10 seconds a visitor should know:

- What the store is
- Whether events are happening
- What products are sold
- Where the store is located
- How to contact them

Within 30 seconds a visitor should be able to:

- Find an event
- Browse products
- Join Discord
- View store hours
- Start shopping

# Design Philosophy

The redesign should feel:

- Modern
- Welcoming
- Premium
- Organized
- Community focused
- Easy to navigate
- Mobile first

Avoid:

- Visual clutter
- Walls of links
- Tiny text
- Information overload
- Hidden navigation
