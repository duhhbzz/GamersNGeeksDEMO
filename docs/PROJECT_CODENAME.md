# Project Codename

## Project Nexus

**Project Nexus** is the internal codename for the Gamers N Geeks modern website redesign.

A local game store acts as a nexus where multiple communities and hobbies meet:

- Trading card games
- Tabletop role-playing games
- Miniature gaming
- Board games
- Model building
- Painting and hobby supplies
- Organized events
- Local gaming communities

The codename is intended for internal planning, development milestones, and documentation.

The client-facing project name remains:

> **Gamers N Geeks Modern Website Redesign**
