# 🔍 Shopify Website Audit

---

# Overview

This document reviews the current Gamers N Geeks website from the perspective of a new customer.

The goal is to identify opportunities for improvement while recognizing the strengths of the existing implementation.

This audit focuses on user experience, navigation, accessibility, and presentation—not the business itself.

---

# Existing Technology

## Platform

- Shopify
- Shopify Theme
- TCGPlayer Pro Integration
- Tockify Event Calendar
- Shopify Apps
- Google Analytics
- Facebook Pixel

# Strengths

The current website already has several things working well.

## Excellent Inventory

The store offers an impressive selection of:

- Trading Card Games
- Board Games
- Miniatures
- RPG Supplies
- Paints
- Accessories
- Singles
- Graded Cards

The breadth of inventory is a major competitive advantage.

The backend is already handling:

## Community Presence

- Discord
- TikTok

# Areas for Improvement

## Homepage

Current observations:

- Information overload
- Weak visual hierarchy
- Too many competing elements
- Difficult to identify primary actions

Recommendation:

Create a focused landing experience.

---

## Navigation

Current observations:

- Large vertical navigation
- Nested menus
- Difficult to scan
- Mobile experience is challenging

Recommendation:

Modern horizontal navigation with a mega menu.

---

## Branding

Current observations:

- Brand personality exists
- Presentation feels inconsistent

Recommendation:

Preserve the identity while modernizing typography, spacing, and layout.

---

## Events

Current observations:

Events are valuable but visually buried.

Recommendation:

Feature upcoming events near the top of the homepage.

---

## Products

Current observations:

Products are available but difficult to discover.

Recommendation:

Create curated product sections.

Examples:

- New Arrivals
- Staff Picks
- Weekly Favorites
- Featured Collections

---

## Mobile Experience

Current observations:

Desktop-first layout.

Navigation requires significant scrolling.

Recommendation:

Design mobile first.

---

## Visual Hierarchy

Current observations:

Nearly every section competes equally for attention.

Recommendation:

Guide users through the page using spacing, typography, and contrast.

---
